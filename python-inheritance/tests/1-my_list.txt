Tests for the MyList class
==========================

Check instantiation:

>>> MyList = __import__('1-my_list').MyList
>>> my_list = MyList()
>>> print(type(my_list))
<class '1-my_list.MyList'>

>>> print(my_list)
[]

Check that it inherits from list:

>>> issubclass(MyList, list)
True

>>> isinstance(my_list, list)
True

>>> print(MyList.__bases__)
(<class 'list'>,)

Check __str__:

>>> str(MyList([1, 2, 3]))
'[1, 2, 3]'

>>> print(MyList([4, 5]))
[4, 5]

Check append():

>>> my_list = MyList()
>>> my_list.append(1)
>>> print(my_list)
[1]

>>> my_list.append(4)
>>> print(my_list)
[1, 4]

Check print_sorted() with sorted append:

>>> my_list = MyList()
>>> my_list.append(1)
>>> my_list.append(2)
>>> my_list.append(3)
>>> my_list.print_sorted()
[1, 2, 3]

Check print_sorted() with not sorted append:

>>> my_list = MyList()
>>> my_list.append(1)
>>> my_list.append(4)
>>> my_list.append(2)
>>> my_list.append(3)
>>> my_list.append(5)
>>> print(my_list)
[1, 4, 2, 3, 5]

>>> my_list.print_sorted()
[1, 2, 3, 4, 5]

The original list keeps its order:

>>> print(my_list)
[1, 4, 2, 3, 5]

Check print_sorted() with not sorted append and a negative number:

>>> my_list = MyList()
>>> my_list.append(3)
>>> my_list.append(-1)
>>> my_list.append(2)
>>> my_list.append(-7)
>>> my_list.append(0)
>>> my_list.print_sorted()
[-7, -1, 0, 2, 3]

>>> print(my_list)
[3, -1, 2, -7, 0]

Check print_sorted() with an empty list:

>>> my_list = MyList()
>>> my_list.print_sorted()
[]

Check that print_sorted() gives a sorted copy and leaves the list alone:

>>> my_list = MyList([3, 1, 2])
>>> my_list.print_sorted()
[1, 2, 3]

>>> print(my_list)
[3, 1, 2]

Duplicates and one item:

>>> MyList([2, 2, 1, 1]).print_sorted()
[1, 1, 2, 2]

>>> MyList([5]).print_sorted()
[5]
