# Python - Network #0

Bash scripts that use curl to send HTTP requests and read the responses.

- 0-body_size.sh: size of the response body in bytes
- 1-body.sh: body of a 200 response, following redirects
- 2-delete.sh: sends a DELETE request
- 3-methods.sh: HTTP methods the server accepts
- 4-header.sh: sends a custom header
- 5-post_params.sh: sends POST parameters
